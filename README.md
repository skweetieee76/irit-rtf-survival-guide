# irit-rtf-survival-guide
# 🎓 Гайд и интерактивный чек-лист первокурсника ИРИТ-РТФ УрФУ

Веб-справочник и интерактивный трекер адаптации для студентов 1 курса ИРИТ-РТФ. Помогает быстро разобраться с сервисами университета (БРС, Moodle, личный кабинет), навигацией по корпусу на Мира, 32 и стартом в ИТ-проектах.

## ✨ Что внутри
- **Интерактивный чек-лист (`index.html`):** сохраняет прогресс выполнения задач прямо в браузере (`localStorage`).
- **Раздел «Учёба и сервисы»:** ссылки и памятка по основным платформам УрФУ.
- **Навигация по Р-корпусу:** советы по поиску аудиторий и коворкингов.
- **Старт в ИТ:** чек-лист для выхода на первый хакатон.

## 🌐 Демо-версия
Открыть интерактивный чек-лист можно по ссылке: `https://github.io`

## 🛠 Технологии
- HTML5 / CSS3 (адаптивная вёрстка)
- Vanilla JavaScript (`localStorage` для сохранения галочек)
- GitHub Pages (хостинг)
